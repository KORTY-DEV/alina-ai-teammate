# Выбор локальной модели

## Текущий выбор

`qwen3.5:4b` остаётся production-моделью по умолчанию для текущего ПК.

Причины:

- единственная из установленных моделей, которая оставляет рабочий VRAM-бюджет рядом с полной Factorio на High sprites;
- прошла реальные E2E-намерения `mine_resource` и `resolve_shortage` с русскими естественными формулировками;
- strict JSON Schema, `think: false`, temperature 0 и grounded-валидация дают повторяемый безопасный план;
- холодный ответ занимает примерно 6.6–6.8 с, из которых около 4.0–4.3 с приходится на загрузку;
- `keep_alive: 0` освобождает VRAM после каждого редкого решения.

## Измерение High sprites + atlas 8192

| Показатель | Значение |
|---|---:|
| Factorio internal VRAM | 3160.41 МБ |
| GPU total до Factorio | 1344 MiB |
| GPU total в меню Factorio | 4408 MiB |
| Factorio + холодная qwen peak | 7612 MiB |
| Пиковая загрузка GPU | 99% |
| Ответ self-test | 6.61 с |
| Загрузка модели | 4.27 с |
| Свободный запас в пике | 580 MiB |

Краткий пик GPU ожидаем во время загрузки/вычисления LLM; модель не участвует в тиках Factorio и после ответа выгружается.

## Почему не установленные 8B/9B

Установленные альтернативы занимают 5.7–6.5 ГБ только файла модели. При 4408 MiB уже занятой VRAM им потребуется существенный CPU offload или вытеснение игровых текстур, что ухудшит latency и стабильность FPS. Они не проходят аппаратный gate для основного режима «Factorio + локальная модель одновременно», поэтому их большая параметрическая ёмкость не делает их более подходящими для этой машины.

## Условия пересмотра

Выбор не считается вечным. Модель меняется только если расширенный eval покажет повторяемые ошибки 4B на mod-aware планировании и кандидат одновременно проходит:

1. grounded correctness и safety;
2. совместный пик ниже 8192 MiB без постоянного CPU offload;
3. отсутствие заметного провала FPS/UPS;
4. приемлемую задержку редкого решения;
5. отсутствие необходимости менять deterministic low-level архитектуру.

До такого измерения скачивание или автоматическое переключение на другую модель отключено.
