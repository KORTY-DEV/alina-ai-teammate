# Установка и запуск

## Что выбрать

У Алины есть два режима запуска:

1. **Полный локальный режим** — рекомендуемый вариант. Использует репозиторий, локальный bridge и локальную модель для ограниченных высокоуровневых запросов.
2. **Только Factorio-мод** — самый простой вариант. Основная детерминированная автономия работает внутри Factorio без локальной модели.

## Полный локальный режим на Windows

### Требования

- Factorio 2.1;
- .NET 8 SDK;
- Ollama;
- несколько гигабайт свободного места для локальной модели.

Однократная установка зависимостей:

```powershell
winget install Microsoft.DotNet.SDK.8
winget install Ollama.Ollama
```

После установки Ollama должен быть запущен.

### Нужно ли отдельно скачивать модель

Нет. При первом запуске `START_ALINA_PLAYABLE.cmd` или `START_ALINA_NEW_GAME.cmd` launcher проверяет наличие `qwen3.5:4b` и, если модели ещё нет, автоматически выполняет её загрузку через Ollama. Это происходит один раз; последующие запуски используют уже установленную модель.

Если Ollama установлен, но его локальный сервис не запущен, launcher остановится с понятным сообщением и ничего не изменит в Factorio.

## Продолжить существующую фабрику

1. Полностью закрой Factorio.
2. Запусти `START_ALINA_PLAYABLE.cmd`.
3. На первом запуске launcher выберет самый свежий обычный `.zip`-сейв Factorio и создаст отдельную рабочую копию `%APPDATA%\Factorio\saves\Alina-Playable.zip`.
4. Исходный сейв не становится рабочим сейвом Алины и не перезаписывается launcher-ом.
5. Мод Алины включается без изменения состояния остальных модов.
6. Запускается локальный bridge.
7. Factorio открывает `Alina-Playable.zip`.

Дальше `START_ALINA_PLAYABLE.cmd` продолжает именно эту безопасную копию.

Чтобы сознательно пересоздать её из самого свежего сейва/автосейва:

- закрой Factorio;
- запусти `RESET_ALINA_PLAYABLE_FROM_LATEST_SAVE.cmd`.

Перед заменой текущая `Alina-Playable.zip` сохраняется в резервную папку `.alina-runtime`.

## Начать совершенно новую игру вместе с Алиной

1. Полностью закрой Factorio.
2. Запусти `START_ALINA_NEW_GAME.cmd`.
3. Launcher проверит зависимости и модель, включит мод Алины и запустит bridge.
4. Factorio откроется в обычном главном меню.
5. Нажми **Новая игра**, настрой карту и моды обычным способом и начни игру.

Существующий сейв для этого режима не нужен. Новая карта сохраняется стандартным механизмом Factorio под выбранным игроком именем.

## Нестандартный путь к Factorio

Launcher автоматически проверяет типичную Steam-установку и несколько стандартных путей. Если `factorio.exe` находится в другом месте, можно запустить напрямую:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-AlinaPlayable.ps1 -FactorioExe "D:\Ваш\путь\Factorio\bin\x64\factorio.exe"
```

Для новой игры добавь `-NewGame`.

## Только Factorio-мод

Если локальная модель не нужна, установи архив `alina-ai-teammate_0.1.0.zip` обычным способом в папку `%APPDATA%\Factorio\mods` или через Mod Portal.

Основная автономия, World Model и поддерживаемые игровые команды работают внутри Factorio. Полный локальный режим нужен для дополнительных ограниченных высокоуровневых запросов.

## Первый smoke test

После загрузки мира:

1. GUI не должен падать.
2. Через несколько секунд должна заполниться строка `Карта: ... объектов, ... чанков`.
3. В полном локальном режиме Bridge должен стать `подключён`.
4. Ничего не пиши 20–30 секунд: Алина должна сама анализировать базу.
5. Затем можно написать `Аля, продолжай развивать базу` или дать конкретный приоритет.

## Если что-то не запускается

- `.NET 8 SDK` не найден — установи `Microsoft.DotNet.SDK.8` через winget.
- `Ollama` не найден — установи `Ollama.Ollama` через winget.
- Ollama не отвечает — запусти приложение Ollama и повтори запуск.
- Модель отсутствует — launcher скачает `qwen3.5:4b` автоматически.
- Factorio не найден — укажи `-FactorioExe` вручную.
- Ошибка bridge — смотри `.alina-runtime\logs\bridge.stderr.log`.
