# Установка и запуск

## Обновление существующего проекта

1. Закрой Factorio.
2. Сделай копию текущей папки проекта при желании.
3. Распакуй этот архив в выбранный `<project-root>` с заменой файлов.
4. Не удаляй `%APPDATA%\Factorio\saves\Alina-Playable.zip`, если хочешь продолжить текущий playable-прогресс.
5. Запусти `START_ALINA_PLAYABLE.cmd`.

## Новый playable-copy

Чтобы пересоздать его из самого свежего сейва/автосейва:
- закрой Factorio;
- запусти `RESET_ALINA_PLAYABLE_FROM_LATEST_SAVE.cmd`.

## Первый smoke test

После загрузки:
1. GUI не должен падать.
2. Через несколько секунд должна заполниться строка `Карта: ... объектов, ... чанков`.
3. Bridge должен стать `подключён`.
4. Ничего не пиши 20–30 секунд: Алина должна сама анализировать базу.
5. Затем проверь локальную команду `добудь железа` — она не должна запускать Qwen и не должна замораживать Factorio.
